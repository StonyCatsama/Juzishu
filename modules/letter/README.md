# letter · 信

她一天的信。三份，各干各的活。

| 文件 | 给谁 | 写什么 |
|---|---|---|
| `YYYY-MM-DD.md` | 人读 | 叙事。有画面，不写统计数字 |
| `ledger.json` | 闸门与审计 | 今天主动说了几次、哪次是自发 |
| `events.jsonl` | 程序 | 几点醒、写了哪段、谁改了什么 |

## 对外

```
read(id, date)          → 当天全文
append(id, slot, text)  → 往某一段接
event(kind, detail)     → 追加一条事件
ledger(id)              → 今天的账
```

## 规矩

- 叙事不背统计。想说“今天说了几轮”，放账本，别写进信。
- 事件只记事实：几点、做了什么。不写“因为什么”。
- 不重写已发生的事，只往后接。
