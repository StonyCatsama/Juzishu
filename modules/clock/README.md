# clock · 时钟

窗口固定，时刻随机。她按自己的节奏醒，不按整点。

## 对外

```
tick(now)                 → 这一拍要不要做事
plan(characterId, date)   → 今天的窗口与计划
catchUp(characterId)      → 错过窗口时补一次或记账
```

## 两类醒

- **写档**：窗口到了就做，有任务。
- **自发**：窗口内评估，心情有波动 / 有牵挂未落地 / 空闲够久，才投回合。

## 规矩

- 宿主关了钟就停。重新起来先 `catchUp`，不能静默丢档。
- 与系统巡检并存期间，必须防重复：同一窗口只做一次。
- 投回合走 `sessions.sendCustom({ triggerTurn: true })`，投到自己的活动会话，不进主对话。
